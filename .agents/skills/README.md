# Antigravity Agent Skills Catalog

Pustaka kemahiran (*Agent Skills*) ini dipasang khusus dalam direktori `.agents/skills/` untuk memperkasakan ejen pengekodan AI Google Antigravity dalam projek **Refinery Digital (PRD-REF-001)**.

Ejen AI akan mengaktifkan kemahiran-kemahiran ini secara automatik (Progressive Disclosure) sebaik sahaja tugas anda menyentuh skop berkaitan.

---

## Cara Antigravity Menggunakan Kemahiran Ini

1. **Automatik (Zero-Config):** Setiap kali anda memberi arahan berkaitan reka bentuk UI, pembaikan pepijat, atau penulisan API, Antigravity akan membaca fail `SKILL.md` yang sepadan secara automatik di latar belakang.
2. **Kekal & Boleh Dikongsi:** Folder `.agents/skills/` ini disimpan terus di dalam repositori Git projek, membolehkan anda dan sesiapa sahaja dalam pasukan menggunakan panduan yang konsisten pada masa hadapan.
